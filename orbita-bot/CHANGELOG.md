# 0.2.0

- Launcher con validación de Node y errores legibles de puerto y permisos.
- Dependencias de escritorio, navegador y móvil separadas del motor.
- Cliente Android Capacitor 8 y scripts para construir APK.
- Pantalla de conexión con URL y clave, CORS explícito y autenticación remota.
- Recuperación de sesión, timeout y errores de red comprensibles.

- Correcciones para envío vacío, doble envío y actualizaciones concurrentes.
- Márgenes de Android, teclado, botones táctiles, botón Atrás y exportación nativa.
- 23 pruebas aprobadas. APK y UI real pendientes de verificación externa.
